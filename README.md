## 作品について

文禄元年元日の宴で、前内府勧修寺の九十の賀を祝って詠まれた題詠の歌。九条・菊亭・持明院・烏丸らの公家や門跡、民部卿法印玄以・紹巴らが春から祝言までの題を一首ずつ詠み、関白秀次の祝言の歌で結ぶ。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。
